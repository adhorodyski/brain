The four genuine losses, stated plainly

Behaviour can't be encoded

No skills, no packages. A preference stays a sentence a host may re-read. Hermes and Kody both let a learned behaviour become a thing. Revisit when the instructions budget regularly fills up.

Nothing curates the archive

No one notices note 40 contradicts note 61. Every design here delegates to whichever model is writing. Cheapest gap to close: one nightly call on the AI binding — free tier covers it, and it costs no package.

Guaranteed delivery is one mechanism

Server instructions are dropped or truncated by real hosts. The block appended to every tool response is the only path we control — and re-sending it constantly is what stops compaction eating it.

No reasoning of our own

The request path holds no model call. Accepted: the host holds the notes and does the thinking, so one brain turn was really two model calls producing one answer. This is the loss that turns "brain" into "archive with good manners".

Skipped on purpose — with the reason that ends the debate

Vectors

(vectors + queries) × dims billed per query. 30M free/month ÷ 2.05M per query = ~14 semantic searches a month. And weak on the exact identifiers that matter most.

Transcripts

You asked for facts and decisions, not messages. Kody stores none for connected hosts — and distilling them would itself be an inference call.

Tenancy / boxes

The fear was my wife deleting my note, not a stranger reading it. That's one owner column and one comparison — not per-person Durable Objects and a token-to-box map.

OAuth 2.1

Only ChatGPT needs it. pi, Codex, Cursor, Claude Code and claude.ai (static credential, beta) all take a bearer token, and pi skips its OAuth flow outright when an Authorization header is present. Permanent, not deferred.
